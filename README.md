# CorpComm Jobs Prototype

A clickable prototype of a redesigned job tracker for the Corporate Communications team: projects list, board, calendar, workload, dashboard, PDF review routing, designer inbox and a Notion link for social posts.

**All jobs and people in it are made-up sample data.**

## Opening it

Visit the GitHub Pages link for this repository and enter the access code. Ask the repository owner for the code.

The page is encrypted with the access code (AES-256 with a PBKDF2-derived key), so the prototype can't be read from the page source without it. Tick "Remember me on this device" to skip the code next time; "Lock prototype" in the sidebar forgets it.

## Notes

- Changes you make (moving jobs, comments, approvals) are saved in your own browser only. Nobody else sees them.
- "Reset sample data" in the sidebar starts over.
- Works in current Chrome, Edge, Safari and Firefox.
